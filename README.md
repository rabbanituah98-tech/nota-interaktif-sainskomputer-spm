# Nota Sains Komputer SPM

Nota last minit Sains Komputer SPM Tingkatan 4 dan 5.
Disediakan oleh **Cikgu Rabbani, SMK Dato' Undang Musa Al-Haj, Jelebu**.

## Kandungan folder

| Fail | Fungsi |
|---|---|
| `index.html` | Laman nota penuh (fon dan semua kod sudah di dalam satu fail, tidak perlu Internet luar) |
| `manifest.webmanifest` | Membolehkan nota dipasang sebagai ikon di skrin utama telefon |
| `sw.js` | Simpan nota supaya boleh dibuka walaupun tanpa Internet selepas lawatan pertama |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`, `icon.svg`, `icon-maskable.svg` | Ikon shortcut telefon (Android dan iPhone) |

## Cara terbitkan di GitHub Pages

1. Log masuk ke GitHub, tekan **New repository**. Beri nama, contoh `nota-sains-komputer`. Pilih **Public**, kemudian **Create repository**.
2. Dalam repository baharu, tekan **uploading an existing file**. Seret **semua fail dalam folder ini** (bukan folder itu sendiri) ke dalam kotak, kemudian tekan **Commit changes**.
3. Pergi ke **Settings → Pages**. Di bawah *Build and deployment*, pilih **Deploy from a branch**, branch **main**, folder **/ (root)**, tekan **Save**.
4. Tunggu 1 hingga 2 minit. Pautan akan muncul di atas halaman yang sama, contohnya
   `https://namapengguna.github.io/nota-sains-komputer/`

Kongsi pautan ini kepada murid melalui WhatsApp atau Google Classroom.

## Cara murid jadikan shortcut di telefon

- **Android (Chrome):** buka pautan, tekan menu ⋮, pilih **Tambah ke skrin utama** atau **Pasang aplikasi**.
- **iPhone (Safari):** buka pautan, tekan butang Kongsi, pilih **Add to Home Screen**.

Ikon cip hijau bertulis "SK" akan muncul di skrin utama dengan nama **Nota SK**.

## Ciri utama

- Mod siang dan malam (butang bulan/matahari), saiz tulisan A− dan A+
- Jam dan tarikh dalam Bahasa Melayu
- Carian pantas (tekan `/` pada komputer) dengan penanda kuning
- Sidebar semua bab dan topik, dengan tanda ✓ bagi topik yang murid tandakan "Saya faham"
- Aktiviti interaktif: Caesar Cipher, get logik, isihan buih, carian perduaan, giliran (queue), makmal SQL
- 39 soalan uji diri dengan penerangan serta-merta, dan 34 kad imbas istilah
- Butang **Cetak**: cetak bab yang sedang dibaca, semua nota, atau kuiz sahaja (ada ruang nama dan skema di halaman akhir)

Kemajuan murid (topik "Saya faham", tema, saiz tulisan) disimpan dalam pelayar telefon masing-masing sahaja.
